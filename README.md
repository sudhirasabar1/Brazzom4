# Brazzom GitHub Pages Website

## What this version does
- The **Watch Video** button opens the featured video page in a new tab.
- The large play icon does the same.
- The sponsored partner button opens the Monetag link in a new tab and is optional.
- The external video page is not a direct MP4 file, so it is linked as a webpage rather than embedded as an HTML video source.

## Upload to GitHub
1. Download and unzip this project.
2. Open your GitHub repository and choose **Add file → Upload files**.
3. Upload `index.html`, `style.css`, `script.js`, `README.md`, and the `assets` folder contents.
4. Commit changes.
5. Open your GitHub Pages website and refresh it. If the old version appears, do a hard refresh with `Ctrl + F5`.

Only share content you are authorized to share, and follow the external website's age restrictions and terms.
